# 🔐 Web Security Log Analyzer

웹 서버 로그를 기반으로 사용자의 요청 패턴과 이상 행위를 분석하고,  
보안 위협 및 비정상적인 접근을 보다 쉽게 확인할 수 있도록 구성한 웹 로그 분석 프로젝트입니다.

단순히 로그 데이터를 나열하는 것이 아니라, 로그 데이터를 수집하고 분석하여  
관리자가 웹 서비스에서 발생하는 이상 징후를 빠르게 파악할 수 있도록  
분석 결과를 화면에서 확인할 수 있는 형태로 구성하는 것을 목표로 했습니다.

---

## 📌 프로젝트 소개

웹 서비스가 운영되면 사용자의 정상적인 요청뿐만 아니라 다양한 형태의 비정상적인 접근이 발생할 수 있습니다.

예를 들어,

- 짧은 시간 동안 특정 IP에서 반복적으로 요청이 발생하는 경우
- 특정 URL에 비정상적으로 많은 요청이 집중되는 경우
- 오류 응답이 반복적으로 발생하는 경우
- 공격으로 의심할 수 있는 요청 패턴이 나타나는 경우
- 특정 시간대에 평소보다 많은 요청이 발생하는 경우

등은 웹 서비스의 상태를 확인하거나 보안 위협을 판단하는 데 중요한 정보가 될 수 있습니다.

본 프로젝트에서는 이러한 웹 서버 로그 데이터를 분석하여  
**요청량, 상태 코드, IP 주소, 요청 경로 및 시간대별 요청 패턴 등의 정보를 확인하고  
이상 행위를 파악할 수 있도록 시각화 및 분석 기능을 구현했습니다.**

---

## 🎯 프로젝트 목표

### 1. 로그 데이터의 효율적인 분석

대량의 웹 로그를 사람이 직접 확인하는 방식에는 한계가 있습니다.

따라서 로그 데이터를 구조화하고 주요 정보를 추출하여  
관리자가 필요한 정보를 빠르게 확인할 수 있도록 구성했습니다.

### 2. 이상 행위 탐지

웹 로그에서 나타나는 반복적인 요청이나 비정상적인 접근 패턴을 분석하여  
보안 위협으로 의심할 수 있는 행위를 확인할 수 있도록 했습니다.

### 3. 데이터 시각화

로그 데이터를 단순한 텍스트 형태로 제공하는 대신  
차트와 통계 형태로 표현하여 전체적인 트래픽 흐름과 이상 징후를  
한눈에 파악할 수 있도록 구성했습니다.

### 4. 웹 기반 분석 환경 구축

분석 결과를 웹 화면에서 확인할 수 있도록 구성하여  
터미널이나 로그 파일을 직접 확인하지 않아도 분석 결과를 확인할 수 있도록 했습니다.

# ⚙️ 주요 기능

## 1. 웹 로그 데이터 분석

웹 서버에서 발생하는 로그 데이터를 기반으로  
각 요청에 대한 주요 정보를 분석합니다.

분석 대상이 되는 주요 정보는 다음과 같습니다.

- Client IP
- 요청 시간
- HTTP Method
- 요청 URL
- HTTP Status Code
- 응답 크기
- User-Agent
- 요청 횟수

로그의 각 데이터를 구조화하여 필요한 조건에 따라 검색하거나  
통계 데이터를 생성할 수 있도록 구성했습니다.

---

## 2. IP 기반 분석

IP 주소를 기준으로 요청 데이터를 분석하여  
특정 IP에서 발생한 요청 패턴을 확인할 수 있도록 구성했습니다.

이를 통해 특정 IP에서 지나치게 많은 요청이 발생하거나  
반복적인 접근이 발생하는 경우 해당 IP를 빠르게 확인할 수 있습니다.

---

## 3. URL / 요청 경로 분석

웹 서비스에서 어떤 URL 또는 API에 요청이 집중되는지 확인할 수 있습니다.

특정 경로에 요청이 집중되는 경우 해당 URL의 사용량을 확인할 수 있으며,  
비정상적으로 많은 요청이 발생하는 경우 이상 행위 분석에 활용할 수 있습니다.

---

## 4. HTTP 상태 코드 분석

HTTP 응답 상태 코드를 기준으로 로그를 분류하여  
웹 서비스에서 발생하는 정상 및 오류 요청을 확인할 수 있습니다.

예를 들어 다음과 같은 상태 코드를 분석할 수 있습니다.

| 상태 코드 | 의미 |
|---|---|
| 200 | 정상 요청 |
| 201 | 리소스 생성 |
| 301 / 302 | 리다이렉션 |
| 400 | 잘못된 요청 |
| 401 | 인증 필요 |
| 403 | 접근 권한 없음 |
| 404 | 존재하지 않는 리소스 |
| 500 | 서버 내부 오류 |

상태 코드의 분포를 통해 웹 서비스에서 오류가 집중되는 구간을 확인할 수 있습니다.

---

로그의 발생 시간을 기준으로 요청량을 분석합니다.

이를 통해 특정 시간대에 요청량이 증가하는 패턴이나  
평소와 다른 트래픽 변화를 확인할 수 있습니다.

# 📊 분석 데이터

프로젝트에서는 로그 데이터를 다음과 같은 관점에서 분석합니다.

### Traffic

전체 요청량과 시간에 따른 요청량 변화를 분석합니다.

### IP

IP별 요청 횟수를 분석하여 특정 IP의 과도한 접근 여부를 확인합니다.

### URL

요청이 집중되는 URL 및 API를 확인합니다.

### Status Code

HTTP 응답 코드별 발생 횟수를 분석하여 오류 발생 상황을 확인합니다.

### Time

시간대별 요청 패턴을 분석하여 평소와 다른 트래픽 변화를 확인합니다.
